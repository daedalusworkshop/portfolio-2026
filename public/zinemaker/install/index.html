ZineMaker plugin preview.

One installation gives Codex the skills to make a zine and send the finished sheet to your printer.

Private preview

ZineMaker is currently distributed as a private Codex plugin. Public installation instructions will appear here when its marketplace release is ready.

Use the plugin

Start a new Codex task and ask for the finished thing.

Use $design-zine to make me a pocket zine
about the strange work agents do while we sleep.

How it works

Talk to your agent ZineMaker makes the whole zine Ask your agent to print it Hold it or give it away

Example

you:
make me a pocket zine explaining agent loops
for people who live in Codex

agent:
Made the complete zine.
Open index.html to read it or print printable.pdf.

you:
make pages 6–7 feel stranger

agent:
Revised the ending. The updated files are ready.
